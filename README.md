# 満年齢早見表作成機

公開ページ: https://jpeqtx.github.io/hayamihyo/

基準年を選ぶと、A4横向きにA5サイズ2枚分の満年齢早見表を作成できる単一ページのWebアプリです。印刷とPDF保存に対応しています。

## 使い方

1. 基準年（西暦）を選ぶ
2. 必要に応じて右上の店舗情報をクリックして編集する（自動保存されます）
3. 店舗名の画像がある場合は、左側の欄から読み込める
4. 「印刷 / PDF保存」を押す

## 内容

- 左ページ：満年齢早見表（和暦・西暦・年齢・干支・九星）
- 右ページ：国民の祝日、長寿祝い、二十四節気、行事と雑節

ファイルは `index.html` のみで動作します。
